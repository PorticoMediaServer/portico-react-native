# Manrope

These are the same Manrope 400, 500, 600, and 700 TrueType files used by the Portico Web UI. Prototype 4 bundles them into both Apple runtimes so typography is rendered from one cross-platform family rather than an Apple-only system font.

| File | PostScript name | Portico role |
| --- | --- | --- |
| `manrope-400.ttf` | `Manrope-Regular` | Regular |
| `manrope-500.ttf` | `Manrope-Medium` | Medium |
| `manrope-600.ttf` | `Manrope-SemiBold` | Demi/Semibold |
| `manrope-700.ttf` | `Manrope-Bold` | Bold |
